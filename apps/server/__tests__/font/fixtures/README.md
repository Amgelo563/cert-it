# Font fixtures

Copies of the fixtures of `@cert-it/fonts`, cut down to printable ASCII plus `é`. See that package's fixture README for how they were made.

| File          | Made from                      | License               |
| ------------- | ------------------------------ | --------------------- |
| `basic.ttf`   | Inter, fixed at weight 400     | `LICENSE_INTER`       |
| `basic.woff2` | `basic.ttf`, saved as WOFF2    | `LICENSE_INTER`       |
| `basic.otf`   | Inconsolata, with CFF outlines | `LICENSE.INCONSOLATA` |

Both fonts are under the SIL Open Font License 1.1, which allows changing and redistributing them.
